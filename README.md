# 关系状态表（social_state）

> 给麦麦的每个联系人记一本账——好感、心情、冷落、话题线头、人物关系边，全部由 LLM 语境化自动维护。麦麦从此知道"谁是谁、关系怎么样、上次聊到哪"，并且克制得像个真人。

## ✨ 功能特性

### 📒 关系账本
| 字段 | 含义 | 范围 | 变化规则 |
|------|------|------|----------|
| 好感度 affinity | 麦麦有多喜欢这个人 | -100 ~ 100 | **感知器 LLM 自动打分**（±10/次钳制）+ 手动命令 |
| 今日心情 mood | 今天互动带来的心情偏移 | -50 ~ 50 | **感知器自动打分**（±25/次钳制），隔天自动衰减归零 |
| 被冷落指数 ignore | 最近 ta 对麦麦的回应有多冷淡 | 0 ~ 100 | 每天自动缓解（默认 -10/天） |
| 待续线头 thread | 没兑现的话题钩子（"周末约了漫展"） | 带到期时间的列表 | **感知器从对话自动挖掘**，默认 10 天有效、30 天封顶，过期/兑现/聊死自动清 |
| 互动时间 | 对方最后发言 / 麦麦最后回复 / 累计条数 | 时间戳 | 自动记录 |
| 关系边 edge | 谁和谁是敌人/朋友（站队数据） | -1 ~ 1 | **感知器从群聊冲突抽取** |

### 🧠 感知器（自动打分，省 token）
- **打分语境化**：同一句话在不同关系温度下分数相反——"我喜欢你"在好感 0 时是尴尬负分，在暧昧期才是正分
- **攒批评估**：不是每条消息都调 LLM——消息进缓冲区，攒够间隔（默认 90 秒）后一次调用评估整轮对话
- **线头自动挖掘**："周末要去漫展""欠你一顿火锅"→ 自动记钩子（LLM 预估时限，30 天封顶），兑现/聊死/过期自动清
- **群冲突抽取**：识别真正的辱骂/攻击（结合双方反应区分玩梗与真冲突）→ 记敌对关系边

### 💬 群聊自动回味（v0.4.3 新增）
- 全群攒够一批消息（默认 20 条）→ 静默几分钟 → **一次 LLM 调用批量更新所有人的印象**
- 结合**双方反应**判断玩笑与冲突：互怼后继续正常聊天=玩梗不计入，一方翻脸=真冒犯才扣分
- 平淡闲聊的人不硬给分（"更新 0 人"是设计行为，不是故障）
- 三重保障：静默去抖 / buffer 快满立即评估 / 维护循环 5 分钟强制救回，消息零丢失

### 🌙 生活日程
每天自动生成麦麦的日程（按人设排 4~6 个时段）：深夜被叫=在被窝里迷迷糊糊，问"在干嘛"能答出正在干嘛。

### 📢 主动中枢（默认关闭）
每 15 分钟检查一次"有没有值得主动找人说句话"的理由：
- **临期线头**（最硬的由头）："有条快过期的心事想问 ta：周末约了漫展（还剩 1 天）"
- **适度沉默**：2~7 天没聊且好感不错 → 随口问候近况
- **门槛保护**：好感低于门槛、冷落超标、深夜、当日超限、同人冷却——一律不主动
- **planner 终审**：冲动过闸后递给主程序 planner（`maisaka.proactive.trigger`），"说不说、怎么开口"由它定——大概率"憋回去"也是拟人

### 🕊️ 和解信号
好感为负但最近连续互动态度改善时，注入"ta 最近态度明显在改善、气消得差不多了，语气可以软下来给个台阶"——打破"永远不理"的死循环。

### 💉 回复前注入
每次回复前自动注入对方的关系温度和临期线头：对好感 35 的人看到"好友，明显偏爱"，对冷落指数 60 的人看到"热情放低，别过度主动"。**克制是自动发生的**，没有任何写死的次数。

## 📦 安装

**方式一：插件市场**（推荐）——在 WebUI 插件市场搜索"关系状态表"一键安装。

**方式二：手动安装**——把本仓库整个文件夹放到 MaiBot 的 `plugins/` 目录，重启麦麦。

> 首次安装后需要重启一次麦麦（能力声明不走热重载）。

## 🚀 快速开始

1. 启动后日志出现：`[关系状态表] 已加载 ... 感知器：LLM 任务=utils...`
2. 给麦麦发 `/关系帮助`，它会回一份说明
3. 随便聊几句 → 等 90 秒后的下一条消息触发评估 → 日志出现 `[感知器] 昵称：好感+3 心情+5（原因...）` → 发 `/关系` 看到数值在动

## 🕹️ 命令

```
/关系                       私聊=查自己；群里=最近互动 top5
/关系 <QQ号或昵称>           查指定的人
/今天                       查看麦麦今天的日程
/ss_set <QQ号> <字段> <值>   手动调账（仅主程序操作员 operator 可用）
/关系帮助                   说明
```

`/ss_set` 示例（把"考试线头"预埋进去，之后麦麦聊到相关话题可能自然问起）：

```
/ss_set 123456 affinity 30
/ss_set 123456 thread 周末约了漫展，别忘了问去不去
/ss_set 123456 thread 无        ← 清除线头
```

字段：`affinity` 好感 / `mood` 心情 / `ignore` 冷落 / `thread` 线头（可加 `#天数` 如 `...#1`）。

## ⚙️ 配置（WebUI 插件配置页）

| 配置 | 默认 | 说明 |
|------|------|------|
| **感知器** | | |
| 感知器总开关 | 开 | LLM 自动评估好感/心情/线头（消耗少量 token） |
| LLM 任务名 | utils | model_config.toml 的任务键，走主程序配置不用填 Key |
| 私聊评估间隔（秒） | 90 | 攒批评估的最小间隔，越大越省 |
| 群冲突抽取 | 开 | 识别群聊真冲突，记敌对关系边 |
| 群聊自动评估 | 开 | 全群攒批自动更新印象（无需 @） |
| 群回味触发条数 | 20 | 全群攒多少条消息触发一次回味 |
| 群回味间隔（秒） | 3600 | 同一人两次被回味的最小间隔 |
| **生活日程** | | |
| 人设简介 | 空 | 强烈建议填写（身份/年龄/喜好），日程严格按人设生成 |
| 起床/睡觉时间 | 8 / 23 | 深夜被叫=在被窝里迷迷糊糊 |
| **主动中枢** | | |
| 主动中枢开关 | 关 | 确认日常效果后再开（需重启一次生效） |
| 每日主动下限/上限 | 2 / 3 | 每天主动次数在区间内随机（模拟真人波动） |
| 好感门槛 | 20 | 低于此值绝不主动 |

## 📁 数据存储

`data/plugins/<插件ID>/social_state.sqlite3`（SQLite，三张表）：

- `person_state` —— 每人一行，主表
- `events` —— 事件流水（最近 5000 条自动滚动清理）
- `relation_edge` —— 人物关系边（站队数据）

**person_id 与主程序完全对齐**（`md5(platform_user_id)`），本表可直接对上 A_Memorix 的人物画像，无需转换。

想清零重来：关麦麦 → 删掉 `social_state.sqlite3` → 开机。

## ☁️ 云端部署与完全回退

插件是纯旁路观察 + 独立存储，**从设计上保证可完全回退**：从不写主程序数据库、零外部依赖、所有 LLM 调用带 60 秒硬熔断。

**部署**：
1. 上传插件文件夹到云端 `plugins/`——只带 `_manifest.json`、`plugin.py`、`README.md`，**不要带 config.toml**（首次启动按默认配置生成）
2. 重启麦麦：`systemctl restart maibot`
3. 验证：`journalctl -u maibot | grep 关系状态表`

**云端成本提示**：真实群聊下每个活跃群每攒 20 条消息一次批量 LLM 调用（一次评一批人）；私聊每 90 秒活跃对话最多一次。群多的话在 WebUI 调大批次数或增大间隔。

**完全回退**（删除即恢复原状）：
```bash
rm -rf plugins/social_state
rm -rf data/plugins/github.ZhaoCang-QWQ.social-state
systemctl restart maibot
```

## 🔒 隐私说明

- **`/关系` 群内隐私模式**：群内 top5 只显示昵称 + QQ 尾号（不显示心情/冷落/线头）；带目标查询（查别人）在群内仅限**本人**或**操作员**——不会向全群广播他人的关系账本。私聊麦麦不受限制。
- **LLM 数据边界**：感知器评估与群聊回味会把**聊天原文**发送给你在主程序配置的 LLM 服务（任务名默认 `utils`，走主程序已有的模型配置与 API Key）。插件自身不做任何额外上传；对数据敏感的群，可在 WebUI 关闭「群聊自动评估」或整个感知器。
- 数据全部存本地 SQLite，插件不连接任何第三方服务。

## ❓ 常见问题

- **感知器没反应？** 日志搜 `[感知器]`：LLM 调用失败会写原因（任务名不存在→改配置里的 LLM 任务名）；间隔没到属正常。
- **群回味日志出现"LLM 调用硬熔断"？** 模型服务偶发无响应，60 秒强制掐断属保护机制，偶发一两次无碍；频繁出现建议换更稳的模型任务。
- **启动失败报「插件配置文件缺少 plugin.config_version 版本号」？** 删除插件目录下的 `config.toml` 再重启（会按默认配置重新生成），或在 WebUI 重新保存一次该插件配置。
- **改了 plugin.py 会自动重载吗？** 会，麦麦监测 plugins 目录变化自动热重载。
- **hook 会不会拖慢聊天？** 钩子都是纯本地 SQLite 读写（毫秒级）；LLM 评估走异步任务且带 60 秒硬熔断，注入失败静默放行——绝不卡回复。
- **token 消耗多大？** 私聊每人每 90 秒活跃对话最多一次轻量评估；群聊每攒 20 条一次批量评估；都是几百 token 的短调用。嫌多就调大批次数/增大间隔或关掉感知器。
